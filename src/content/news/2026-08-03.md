# 2026-08-03 · AI 行业动态

## 1. 阿里巴巴发布新一代基座大模型Qwen3.8

阿里巴巴正式发布新一代基座大模型Qwen3.8，整体性能跻身全球大模型第一梯队。官方还宣布Qwen3.8-Max、Qwen3.8-27B将于近期开源，配套能力可支持自主生成完整Agent应用。

- [阿里Qwen3.8正式发布，编程与办公再进化，推理更快更稳定](https://www.qbitai.com/2026/08/465215.html) `cn:qbitai`

## 2. 阿里旗下千问办公开启全用户公测

阿里巴巴旗下办公AI产品“千问办公”正式开启公测，面向个人及企业用户开放。产品已接入最新旗舰模型Qwen3.8，可覆盖多场景办公效率需求。

- [阿里“千问办公”开启公测](https://www.qbitai.com/2026/08/465211.html) `cn:qbitai`

## 3. 华为诺亚开源AI Agent记忆操作层MindMemOS

华为诺亚正式开源面向AI Agent的可迁移、自演进记忆操作层MindMemOS。该系统可实现Agent记忆与技能的协同进化，解决现有AI“用完即忘”的使用痛点。

- [「天线宝宝」机器人上门做保洁，200元/小时，纯·人工·智能](https://www.qbitai.com/2026/08/464781.html) `cn:qbitai`

## 4. OpenAI发布GPT-5.6 性价比与测试表现双提升

OpenAI正式公布GPT-5.6相关优化，针对Luna和Terra版本下调使用定价，大幅提升模型性价比。官方还披露通过调整两项API设置，GPT-5.6在ARC-AGI-3基准测试中的得分提升三倍。

- [Advancing the price-performance frontier with GPT-5.6](https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6) `blog:openai-news`

## 8. 谷歌推出Gemini API Managed Agents 3.6 Flash

- [Gemini API Managed Agents: 3.6 Flash, hooks, and more](https://blog.google/innovation-and-ai/technology/developers-tools/expanding-managed-agents-gemini-api-3-6-flash-hooks/) `blog:google-ai`

## 9. DeepMind发布Gemini Robotics ER 2机器人系统

谷歌DeepMind正式推出Gemini Robotics ER 2机器人系统，包含Duo与Apollo两款机器人产品。该系统搭载Gemini多模态能力，可适配复杂工业与民用场景操作需求。

- [Introducing Gemini Robotics ER 2](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/gemini-robotics-er-2/) `blog:deepmind`
