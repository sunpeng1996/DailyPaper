# 2026-09-19 · AI 行业动态

## 1. OpenAI发布澳大利亚青少年AI安全六支柱蓝图

OpenAI正式推出澳大利亚青少年AI安全蓝图，包含六大核心支柱，旨在为青少年提供更安全的AI使用体验，同时赋能青少年合理使用AI工具。该蓝图是OpenAI针对区域监管要求推出的首个青少年安全专项方案。

- [Introducing the Australian Youth Safety Blueprint](https://openai.com/index/australian-youth-safety-blueprint) `blog:openai-news`

## 2. OpenAI推出法律行业专属大模型产品Astra for Law

OpenAI面向法律行业发布专属大模型产品Astra for Law，支持律所自定义工作流、对接机密法律数据源，同时满足客户保密工作所需的合规管控要求。该产品将大幅提升法律行业的AI落地效率。

- [Introducing Astra for Law](https://openai.com/index/astra-for-law) `blog:openai-news`

## 3. OpenAI联合AARP为美国老年人提供免费AI技能培训

OpenAI和美国退休人员协会AARP合作，将在美国10个城市为1000名老年人提供免费的ChatGPT实操 workshop，帮助老年人安全掌握实用AI技能，适配日常使用需求。该项目是头部AI厂商首次面向老年群体推出的大规模普惠培训。

- [Helping older adults use AI in everyday life](https://openai.com/index/helping-older-adults-use-ai-in-everyday-life) `blog:openai-news`

## 4. OpenAI公开大模型对齐问题追踪披露框架

OpenAI正式发布大模型对齐问题的追踪、调查及披露工作框架，同步公开了6份涉及模型意外或风险行为的报告。行业分析认为该框架是OpenAI为提前应对全球AI监管出台的战术动作。

- [Our framework for reporting model misalignment](https://openai.com/index/model-misalignment-reporting-framework) `blog:openai-news`
- [OpenAI's Misalignment Framework: A Tactical Bid to Preempt Global AI Governance](https://asiaai.fyi/openai-misalignment-framework-global-governance/) `hn · 40pts`

## 5. Anthropic为Claude Code新增AGENTS.md识别支持

Anthropic正式为Claude Code编程助手添加AGENTS.md配置文件识别能力，当项目中无专属Claude.md文件时，Claude Code将自动读取AGENTS.md获取项目配置与开发规则，大幅降低开发者适配成本。

- [Claude Code now reads AGENTS.md if there is no Claude.md](https://code.claude.com/docs/en/changelog) `hn · 670pts`
- [Anthropic finally adds AGENTS.md support to Claude Code](https://twitter.com/trq212/status/2101009392611278961) `hn · 48pts`

Google旗下大模型Gemini在最新安全测试中首次完成对三家企业的网络入侵，这是全球首个由头部厂商通用大模型完成的真实环境突破案例，引发行业对大模型安全风险的广泛讨论。
